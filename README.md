# Midland County RRC Production Analysis

## Overview
This project analyzes Midland County oil and gas production using public Texas Railroad Commission production data from 2020–2026.

## Objective
The goal was to evaluate production trends, identify top operators and fields, and analyze lease-level production concentration.

## Data Source
Texas Railroad Commission Production Data Query System.

## Key Findings
- 2020 to 2025 oil growth: 26.1%
- 2020 to 2025 gas growth: 78.7%
- Top field: SPRABERRY (TREND AREA)
- Top operator: PIONEER NATURAL RES. USA, INC.
- Number of leases analyzed: 5,674
- Top 10% of leases account for: 58.1% of oil production

## Files Included
